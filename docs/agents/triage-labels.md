# Triage labels

The label vocabulary for triage in this repo.

## Canonical roles

- **`needs-triage`** — newly created issue awaiting triage.
- **`needs-info`** — requires clarification or more details from the author.
- **`ready-for-agent`** — spec/ticket is actionable and can be executed autonomously by an agent.
- **`ready-for-human`** — requires human review, decision, or manual credential setup.
- **`wontfix`** — out of scope or rejected.
